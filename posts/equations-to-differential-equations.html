从"解出一个数"到"解出一条规律"：一般方程与微分方程

2026-09-26 · Steve Chan

初中解 2x + 3 = 7，高中解 x² - 5x + 6 = 0，大学突然冒出来一个 dy/dt = ky， 很多人从这里开始觉得数学"变了味"：怎么方程里还有导数？解出来的怎么不是一个数，而是一个函数？

其实两者是一脉相承的。一句话概括：

一般方程问的是"哪个数满足这个关系"，微分方程问的是"哪个函数满足这个变化规律"。

这篇文章按这个顺序走：

  • 一般方程（代数方程）到底在解什么？
  • 为什么光有一般方程不够，必须引入"导数"？
  • 常见的微分方程有哪些：指数增长、牛顿冷却、Logistic、自由落体、弹簧振动、RC 电路、热方程、波动方程
  • 两者的系统对比：未知量、解的形态、定解条件、解法
  • 最有意思的部分：微分方程如何一次次"退化"回一般方程（特征方程、平衡点、欧拉离散化）

代码都用 Python（numpy），可以直接跑。

0. 一句话主线

一般方程描述"状态"，微分方程描述"变化"。 一般方程的解是一个点，微分方程的解是一条轨迹。

打个比方：

  • 一般方程像一张照片：告诉你"此刻，某个量等于多少"。
  • 微分方程像一条运动规则：告诉你"在任何时刻，这个量正以多快的速度变化"。然后让你反推出整部电影。
# 一般方程：2x + 3 = 7，答案是一个数
x = (7 - 3) / 2
print(x)            # 2.0

# 微分方程：dy/dt = 0.5 * y，y(0) = 1，答案是一个函数
import numpy as np
y = lambda t: np.exp(0.5 * t)
print([round(y(t), 3) for t in [0, 1, 2, 3]])   # [1.0, 1.649, 2.718, 4.482]

第一行的答案是 2.0；第二段的答案是 y(t) = e^{0.5t}——它对每一个时刻 t 都给出一个值。

1. 一般方程：在"数"的世界里找未知数

所谓一般方程（代数方程、超越方程），未知量是一个或几个数。常见的几类：

类型 例子 解 典型意义
一元一次 2x + 3 = 7 x = 2 单价、比例
一元二次 x² - 5x + 6 = 0 x = 2, 3 抛物线与 x 轴交点
线性方程组 x + y = 5, x - y = 1 (3, 2) 多个约束同时满足
高次多项式 x³ - 6x² + 11x - 6 = 0 1, 2, 3 特征值、稳定性
指数/超越方程 2^x = 10、cos x = x x ≈ 3.32、x ≈ 0.739 复利、不动点 
import numpy as np

# 一元二次
print(np.roots([1, -5, 6]))                 # [3. 2.]

# 线性方程组 A x = b
A = np.array([[1, 1], [1, -1]]); b = np.array([5, 1])
print(np.linalg.solve(A, b))                # [3. 2.]

# 超越方程 cos(x) = x：没有公式解，只能数值求
# 牛顿法：x_{n+1} = x_n - f(x_n) / f'(x_n)
f  = lambda x: np.cos(x) - x
df = lambda x: -np.sin(x) - 1
x = 1.0
for _ in range(6):
    x = x - f(x) / df(x)
print(x)                                    # 0.739085...

一般方程的共同点：

  1. 未知量是数（或数组成的向量）。
  2. 解通常是有限个孤立的点：二次方程最多 2 个根，n 次方程最多 n 个根。
  3. 方程本身就够了，不需要额外"初始条件"。
  4. 解不出公式时，可以用数值迭代（二分法、牛顿法）逼近。

注意第 4 点里的牛顿法——它本身就在用导数。导数这个工具，一会儿就会从"辅助"变成"主角"。

2. 为什么一般方程不够用？

一般方程擅长回答"是多少"，却回答不了"会怎样"。

看三个问题：

  • 一杯 90℃ 的咖啡放在 20℃ 的房间里，10 分钟后是多少度？
  • 一个细菌培养皿，每个细菌每小时分裂一次，5 小时后有多少？
  • 一根弹簧被拉开 3 厘米后松手，第 2 秒时它在哪？

这些问题有一个共同点：我们不知道"答案等于什么"，但我们知道"它怎么变"。

  • 咖啡：温差越大，降温越快。
  • 细菌：细菌越多，增长越快。
  • 弹簧：拉得越开，拉回的力越大，加速度越大。

"怎么变"在数学上就是导数：dy/dt 表示 y 随时间 t 的变化率。 把"怎么变"的规律写成等式，就得到了微分方程：

含有未知函数及其导数的方程，叫微分方程。

从一般方程到微分方程，只做了一件事：

一般方程：   F(x) = 0              未知量 x 是一个数
微分方程：   F(t, y, y', y'', ...) = 0   未知量 y(t) 是一个函数

未知量从"数"升级成了"函数"，解从"点"升级成了"曲线"。

3. 常见的微分方程（一阶）

3.1 指数增长 / 衰减：y' = k y

"越多，涨得越快"（k > 0）或"越多，减得越快"（k < 0）。

  • 人口、细菌、复利（k > 0）
  • 放射性衰变、药物代谢（k < 0）

解：y(t) = y₀ · e^{kt}

import numpy as np

k, y0 = np.log(2), 1.0        # 每小时翻倍
t = np.arange(6)
print(y0 * np.exp(k * t))     # [ 1.  2.  4.  8. 16. 32.]

# 碳-14 半衰期约 5730 年：y' = -k y
k = np.log(2) / 5730
print(np.exp(-k * 11460))     # 0.25 —— 过两个半衰期剩 1/4

对照一般方程：2^x = 32 问的是"哪一刻等于 32"（答案 x = 5，是一个数）； y' = ln2 · y 问的是"每一刻是多少"（答案是整条曲线 2^t）。 前者恰好是后者解出来之后，再解的一个一般方程。

3.2 牛顿冷却定律：T' = -k (T - T_env)

降温速度正比于和环境的温差。

解：T(t) = T_env + (T₀ - T_env) · e^{-kt}

import numpy as np

T_env, T0, k = 20, 90, 0.1
T = lambda t: T_env + (T0 - T_env) * np.exp(-k * t)
for t in [0, 5, 10, 30, 60]:
    print(t, round(T(t), 1))
# 0 90.0 / 5 62.5 / 10 45.8 / 30 23.5 / 60 20.2  —— 无限逼近 20℃

3.3 Logistic 方程：y' = r y (1 - y/K)

指数增长太理想了——资源有限。Logistic 在增长率上乘了一个"刹车"因子 (1 - y/K)： y 小时近似指数增长，y 接近承载量 K 时增长趋于 0。

解：y(t) = K / (1 + ((K - y₀)/y₀) · e^{-rt})，一条 S 形曲线。

用途：种群增长、传染病早期传播、产品渗透率，以及神经网络里的 sigmoid 函数——它正是这个方程的解。

import numpy as np

K, r, y0 = 1000, 0.8, 10
y = lambda t: K / (1 + (K - y0) / y0 * np.exp(-r * t))
print([round(y(t)) for t in [0, 3, 6, 9, 12, 15]])
# [10, 100, 551, 931, 993, 999]  —— 慢、快、慢，S 形

3.4 RC 电路充电：RC · V' + V = E

电容充电电压的变化，和牛顿冷却是同一个方程，只是换了物理量：

解：V(t) = E (1 - e^{-t/RC})

这就是微分方程的威力之一：看起来毫不相关的现象，满足同一个方程，就有同一种行为。

4. 常见的微分方程（二阶）

4.1 自由落体：y'' = -g

牛顿第二定律 F = ma 本身就是一个二阶微分方程，因为加速度 a 是位置的二阶导数。

解：积分两次，y(t) = y₀ + v₀ t - ½ g t²

注意：积分两次，就出现两个待定常数（y₀、v₀），所以需要两个初始条件（初始位置、初始速度）。

4.2 简谐振动：y'' = -ω² y

弹簧、单摆（小角度）、LC 电路。"离平衡位置越远，被拉回来的加速度越大"。

解：y(t) = A cos(ωt) + B sin(ωt)

4.3 阻尼振动：y'' + 2ζω y' + ω² y = 0

真实的弹簧会因摩擦慢慢停下。根据阻尼大小 ζ 分三种情况：

  • ζ < 1 欠阻尼：一边振动一边衰减
  • ζ = 1 临界阻尼：最快回到平衡、不振荡（汽车减震器的设计目标）
  • ζ > 1 过阻尼：慢慢爬回平衡

这三种情况怎么判断？答案藏在一个一元二次方程里——见第 6 节。

5. 偏微分方程：未知函数有多个自变量

上面都是常微分方程（ODE）：未知函数只依赖一个变量 t。 如果未知函数同时依赖时间和空间 u(x, t)，就得到偏微分方程（PDE）：

方程 形式 描述
热方程 ∂u/∂t = α ∂²u/∂x² 热量扩散、墨水在水中扩散
波动方程 ∂²u/∂t² = c² ∂²u/∂x² 琴弦振动、声波、电磁波
拉普拉斯方程 ∂²u/∂x² + ∂²u/∂y² = 0 稳态温度分布、静电场
薛定谔方程 iħ ∂ψ/∂t = Ĥψ 量子态演化
纳维-斯托克斯 （略） 流体、天气

一个热方程的小模拟：一根铁棒中间加热，看热量如何往两边摊开。

import numpy as np

n, alpha, dt, dx = 21, 1.0, 0.2, 1.0
u = np.zeros(n); u[n // 2] = 100.0          # 中间一点 100℃
for step in range(50):
    lap = np.roll(u, 1) - 2 * u + np.roll(u, -1)   # 离散的 ∂²u/∂x²
    lap[0] = lap[-1] = 0                           # 两端固定
    u = u + alpha * dt / dx**2 * lap
print(np.round(u, 1))
# 尖峰被"抹平"成一个钟形 —— 这就是扩散

有意思的是：拉普拉斯方程是热方程"等到时间足够久、不再变化"时的样子——令 ∂u/∂t = 0。 这正是下一节要讲的套路。

6. 从微分方程回到一般方程：三条桥

微分方程看起来高了一个维度，但真正解它时，几乎总要落回一般方程。这是理解两者关系的关键。

桥一：平衡点 —— 令导数为 0

"系统最终会停在哪？"停下来就是不再变化，也就是 y' = 0。 于是微分方程 y' = f(y) 的平衡点，就是一般方程 f(y) = 0 的根。

import numpy as np

# Logistic: y' = r y (1 - y/K)，令右边 = 0
r, K = 0.8, 1000
# r y (1 - y/K) = 0  ->  -r/K y² + r y = 0
print(np.roots([-r / K, r, 0]))     # [1000.  0.] —— 两个平衡点：灭绝 与 承载量

再用导数判断稳定性：f'(y*) < 0 稳定（被吸过去），> 0 不稳定（被推开）。 Logistic 里 y = 0 不稳定、y = K 稳定——所以种群总会长到 K。

一般方程的解，是微分方程的"终点"。

桥二：特征方程 —— 猜 e^{rt}，微分变代数

对常系数线性方程 y'' + a y' + b y = 0，猜一个解 y = e^{rt}：

y'  = r e^{rt}
y'' = r² e^{rt}
代入： (r² + a r + b) e^{rt} = 0
因为 e^{rt} ≠ 0：   r² + a r + b = 0

一个二阶微分方程，变成了一个一元二次方程！ 求导变成了乘以 r。 初中学的判别式 Δ = a² - 4b 在这里有了物理意义：

判别式 根 运动
Δ > 0 两个负实根 过阻尼，慢慢回位
Δ = 0 重根 临界阻尼
Δ < 0 共轭复根 -p ± qi 欠阻尼：e^{-pt} 衰减 × cos(qt) 振动 
import numpy as np

omega = 2.0
for zeta in [0.2, 1.0, 3.0]:
    a, b = 2 * zeta * omega, omega**2
    roots = np.roots([1, a, b])
    print(f"ζ={zeta}: Δ={a*a - 4*b:+.1f}, 根={np.round(roots, 3)}")
# ζ=0.2: Δ=-15.4, 根=[-0.4+1.96j -0.4-1.96j]   复根 -> 衰减振荡
# ζ=1.0: Δ=+0.0,  根=[-2. -2.]                   重根 -> 临界阻尼
# ζ=3.0: Δ=+128.0,根=[-11.657 -0.343]            实根 -> 过阻尼

简谐振动 y'' = -ω² y 的特征方程是 r² + ω² = 0，根 r = ±iω， 再借欧拉公式 e^{iωt} = cos ωt + i sin ωt，就得到了 cos 和 sin。 虚数根在这里不再"虚"，它就是振动。

推广到方程组 x' = A x：特征方程变成 det(A - λI) = 0，也就是求矩阵的特征值—— 又是一个多项式方程。特征值的实部全为负，系统就稳定。这是控制理论的基石。

桥三：离散化 —— 把微分方程切成一串一般方程

计算机不会"求导"，它只会加减乘除。数值解法的核心是把导数换成差商：

y'(t) ≈ (y(t + h) - y(t)) / h

代入 y' = f(y)，得到欧拉法：

y_{n+1} = y_n + h · f(y_n)

每一步都是一个普通的代数运算。 一个微分方程，被拆成了无数个首尾相接的一般方程（递推式）。

import numpy as np

# 用欧拉法解 y' = y, y(0) = 1，求 y(1)，精确值应为 e
for h in [0.1, 0.01, 0.001]:
    y = 1.0
    for _ in range(int(1 / h)):
        y = y + h * y
    print(f"h={h}: y(1)≈{y:.5f}, 误差={abs(y - np.e):.5f}")
# 步长越小越准；而 (1 + h)^(1/h) -> e，正是 e 的定义

再看阻尼弹簧的完整轨迹（二阶方程拆成两个一阶：位置 y、速度 v）：

import numpy as np

omega, zeta, h = 2.0, 0.2, 0.01
y, v = 3.0, 0.0                       # 拉开 3cm，静止释放
for step in range(501):
    if step % 50 == 0:
        print(f"t={step*h:4.1f}  y={y:+.3f}")
    a = -2 * zeta * omega * v - omega**2 * y
    y, v = y + h * v, v + h * a
# y 在正负之间来回摆，振幅越来越小

如果用隐式欧拉 y_{n+1} = y_n + h · f(y_{n+1})，未知量 y_{n+1} 出现在两边， 每一步都要解一个一般方程（常用牛顿法）。于是第 1 节里的牛顿法又回来了—— 解微分方程，最后落在反复解一般方程上。

7. 系统对比

维度 一般方程 微分方程
未知量 数（或向量） 函数 y(t)、u(x,t)
方程描述的是 量之间的静态关系 量的变化规律
解的形态 孤立的点（有限个） 一族曲线（无穷多条）
自由度 由方程个数决定 由阶数决定：n 阶有 n 个任意常数
定解条件 不需要 初始条件 / 边界条件
解的存在性 代数基本定理：n 次多项式有 n 个复根 皮卡定理：f 足够光滑则初值问题解存在唯一
公式解 五次及以上一般无根式解（阿贝尔） 绝大多数非线性方程无解析解
数值解法 二分法、牛顿法、高斯消元 欧拉法、龙格-库塔、有限差分/有限元
典型问题 "多少钱""多长""交点在哪" "会怎样演化""最终停在哪""稳不稳定"
线性情形 Ax = b（线性代数） x' = Ax（解为 e^{At}x₀，靠特征值）

几点值得多说一句：

为什么微分方程需要初始条件？ y' = ky 的解是 y = C e^{kt}，C 取任何值都满足。规律只决定"形状"，不决定"从哪出发"。 就像知道"每年涨 5%"，不知道本金，就算不出十年后多少钱。 一般方程没有这个问题，因为它不含导数，没有"积分常数"丢失信息。

为什么微分方程的"解"反而更多？ 一般方程是"约束"，约束越多解越少；微分方程是"规则"，一条规则下可以有无穷多种初始状态， 每个初始状态演化出一条轨迹。所有轨迹放在一起，叫相图或流。

两者的难度来源相同。 一般方程里，线性的 Ax = b 容易，非线性的五次方程没有公式； 微分方程里，线性的 x' = Ax 容易，非线性的三体问题、Navier-Stokes 至今没有通解。 "线性好解，非线性难解"是贯穿两者的同一条分界线。

9. 结语

一般方程是数学的"名词"：它告诉你一个东西是什么。 微分方程是数学的"动词"：它告诉你一个东西怎么变。

牛顿写下 F = ma 的那一刻，物理学从"描述世界的样子"转向了"描述世界的变化规则"—— 从行星轨道到电路、从传染病到股价、从热传导到量子力学，几乎所有定律都以微分方程的形式出现。

但只要真正去解，就会发现它总在回到你熟悉的地方： 平衡点是 f(y) = 0 的根，振动频率是一元二次方程的复根，计算机模拟是一串递推的代数式。

初中的解方程没有白学——它是微分方程每一次落地时踩着的那块地面。

顺带一提：深度学习里的 ResNet x_{n+1} = x_n + f(x_n)，恰好就是欧拉法的样子； 把层数取到无穷、步长取到 0，就得到了 Neural ODE dx/dt = f(x)。 同一条从"离散递推"到"连续微分"的桥，今天也架在神经网络上。
